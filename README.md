# Simple JavaScript Calendar

A compact month calendar built with HTML, CSS, and plain JavaScript. It shows weekday headings, the days in the selected month, and the adjacent month dates needed to complete the week rows.

## Live demo

[Open the calendar](https://selty-tech.github.io/vanilla-js-calendar/)

## Use

Select the previous or next month button to change the displayed month. The buttons work with touch and standard keyboard activation. The calendar adjusts its seven-column layout to the viewport, including narrow phones and landscape screens.

## Features

- Navigate between months, including across year boundaries
- Show adjacent month dates to complete the calendar rows
- Responsive grid with large month navigation buttons
- No dependencies or build step

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/Selty-tech/vanilla-js-calendar.git
cd vanilla-js-calendar
```
